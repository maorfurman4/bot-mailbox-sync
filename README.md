# 📧 מנהל המייל

מסדר את ה-Gmail בתוויות צבעוניות, שלוש פעמים ביום. בתיבה נשאר רק מה שצריך טיפול;
כל השאר בארכיון, בתוך התווית שלו. טלגרם — רק חשבונות וקבלות.

## איך כל מייל ממוין
1. **חסום** (`rules.BLOCK`: פרסומות עלי אקספרס, Alibaba, LinkedIn, Facebook, Instagram...) → לפח + ביטול הרשמה.
   ביטול הרשמה רק בתקן One-Click של השולח. חל גם על מיילים ישנים בתיבה. התראות אבטחה עוברות חסימה.
2. **בלי AI** (חוסך טוקנים): שולח מוכר (`rules.KNOWN`) מקבל קטגוריה קבועה (שולח קבלות — רק כשהנושא נראה כמו קבלה, `RECEIPT_SUBJECT`); מה ש-Gmail סימן כקידום מכירות/רשת חברתית
   ואינו מוגן — זבל.
3. **AI** (gpt-4o-mini) רק לשאר — קריאה אחת לכל 25 מיילים.
4. **הגנה** (`rules.PROTECT`, `PROTECT_SUBJECT`): אפקה, gov.il, מכבי, בנקים, חשבונות, GitHub, Vercel, OpenAI,
   אנשים פרטיים, נושא עם אבטחה/סיסמה/חשבונית — **לא נמחקים לעולם**. "פרסומת" בתחילת/סוף הנושא — תמיד זבל.

| תווית | בתיבה? | מה נכנס |
|---|---|---|
| 📬 חשוב | ✅ | אנשים, ממשלה, מכבי, בנק, כל מה שמחכה לטיפול |
| 🧾 חשבונות | ✅ פתוח / ארכיון אם שולם | חשבונות וקבלות — וגם לבוט הקבלות בטלגרם |
| 🎓 לימודים | ✅ אנשים / ארכיון לדיוור מערכת (`rules.AFEKA_SYSTEM`) | אפקה — דיוור מערכת לפח אחרי 48 שעות, שיחות שענית בהן ואנשים פרטיים לא נמחקים |
| 🔐 אבטחה | ✅ → לפח אחרי 24 שעות | התראות אבטחה, כניסות, סיסמאות, קודים |
| 💻 פיתוח | ארכיון → לפח אחרי יום | GitHub, Vercel, Replit |
| ✈️ הזמנות ונסיעות | ארכיון | טיסות, נסיעות, כרטיסים, אישורי הזמנה |
| 🎟️ קופונים | ארכיון | שוברים וקופונים |
| 📁 כללי | ארכיון | שימושי אבל לא דחוף |
| ⏳ ממתין לתשובה | ✅ | מייל חשוב מאדם שלא ענית לו 3 ימים — יורד לבד אחרי שענית |
| 🗑️ | פח | זבל וחסומים (אפשר לשחזר 30 יום) |

**בוט הקבלות**: ספק, סכום, סטטוס, ה-PDF עצמו, כפתור למייל; כפתור תשלום רק לאתר של הספק או לסולק מוכר.
**חשבון פתוח עם תאריך יעד** → אירוע יום שלם ביומן ("💳 לשלם...") — מופיע בתדריך של דבי.
**כל ה-Gmail, לא רק התיבה**: גם מייל שפילטר ישן העביר ישר לתווית נבדק; חשבון פתוח או מייל חשוב חוזר לתיבה.

## מתי
07:00, 13:00, 19:00 בחורף (08:00, 14:00, 20:00 בקיץ). מיילים מ-3 הימים האחרונים, מכל ה-Gmail, שעוד לא טופלו
(`Mail_Bot_Done` — תווית פנימית, מוסתרת).
הרצה ידנית: Actions → "Mail Manager" → Run workflow:
- **dry_run** — רק מדפיס מה היה עושה, בלי לשנות כלום
- **organize_all** — מסדר בתוויות גם את כל התיבה ו-60 יום אחורה (בלי להזיז, בלי טלגרם ויומן)
- **tidy_inbox** — חד-פעמי: כל מה שבתיבה מקבל תווית ועובר למקום שלו (בלי טלגרם ויומן)
- **merge_labels** — חד-פעמי: מעביר את התוויות הישנות (`MERGE_LABELS`) לתוויות החדשות ומוחק אותן. המיילים עצמם לא נמחקים;
  מה שה-AI חשב לזבל עובר ל"כללי" — לפח רק פרסומת מסומנת או שולח חסום

תקלה → הודעה בבוט הלימודים, וההרצה מסומנת ככישלון.
